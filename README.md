#BTSG


Este script de powershell permite la instalación de Spotify con el bloackeador de anuncios el cual esta hospedado en:  https://github.com/Nuzair46/BlockTheSpot

Puedes ejecutarlo localmente descargandolo y usando esta sentencia desde la terminal:  

    powershell -ExecutionPolicy Bypass -File .\BlockTheSpot-GUI.ps1

Si no deseas descargar el script, puedes ejecutarlo directamente en memoria usando este comando:  

    irm https://raw.githubusercontent.com/srsaiet/BTSG/main/BlockTheSpot-GUI.ps1 | iex

El uso de este script es bajo tu propia responsbilidad. Eres libre de usarlo y/o modificarlo a tu gusto
